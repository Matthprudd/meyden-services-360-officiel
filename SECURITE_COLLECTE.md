# Sécurité de la collecte — meyden-services-360-officiel
**Statut : préparation uniquement, non activée.**
Cette application est un département de MEYDEN Ecosystem OS.
- Les formulaires actuels ne transmettent pas leurs données à un backend sécurisé partagé.
- Aucune donnée personnelle réelle ne doit être collectée dans un registre de démonstration pour l'instant.
- Les données ne doivent pas passer dans l'URL, dans un token public ni dans un dépôt GitHub.
- La prochaine intégration devra utiliser l'API privée de MEYDEN OS avec validation côté serveur, protection anti-abus, accès authentifié au back-office, règles de conservation et politique de confidentialité.
- Les messages de soumission doivent signaler clairement qu'il s'agit d'une **demande de devis**, pas d'un achat ou contrat.
- Ne pas modifier les données ou les anciens outils avant les tests complets et une sauvegarde.
